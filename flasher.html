Прошивальщик ESP32‑S3

Стирает память и прошивает .bin прямо из браузера. Сделан под M5Stack Cardputer. Файл читается у вас на компьютере и на сервер не отправляется.

Этот браузер не подходит

Для работы с USB-портом нужен Chrome или Edge на компьютере (версия 89 и новее). Firefox и Safari не умеют Web Serial. Страница должна быть открыта по https.

1Подключение

Не подключено

Подключите Cardputer кабелем USB и нажмите кнопку. В списке выберите «USB JTAG/serial debug unit» или порт с похожим названием. Если не подключается, включите режим загрузки (подсказка ниже).

2Файл прошивки

Выберите .bin или перетащите сюда
Файл не выбран.

      Как включить режим загрузки Cardputer
      
    
        
  1. Боковой выключатель питания в положение OFF.
    2. 
        
  2. Зажмите кнопку G0 и держите.
    3. 
        
  3. Не отпуская G0, включите питание. Затем G0 можно отпустить.
    4. 
        
  4. Подключите USB к компьютеру. Экран остаётся чёрным, это нормально.
    5. 
      

      
Часто режим загрузки не нужен: страница сама перезапускает плату в загрузчик. Если подключение не получается, сделайте так.

    


    

      Что-то не работает
      
    
        
  • Порт не появляется. Попробуйте другой USB-кабель, не только для зарядки, и другой разъём компьютера.
    • 
        
  • Обрывается на записи. В «Дополнительно» выберите скорость 115200.
    • 
        
  • После прошивки чёрный экран. Выключите и включите устройство выключателем.
    • 
        
  • Порт занят. Закройте M5Burner, Arduino IDE, PlatformIO Monitor и другие вкладки с флешерами.
    • 
        
  • Прошивка не стартует после «Только приложение». Этот файл работает только если загрузчик и таблица разделов уже записаны. После полного стирания нужен полный образ по адресу 0x0.
